# Atlas Notebook Product

## Product Positioning
Atlas Notebook is a focused, Atlas-first companion for Path of Exile players that helps them scan, filter, and remember map information quickly.

## UI Language
The product follows the **Midnight Cartographer** design language:
- Dark indigo base UI for map-first immersion.
- Gold reserved for user identity and preference signals.
- Bright functional accents reserved for wayfinding/filter meaning.

## Interaction Priorities
1. Atlas map readability first.
2. Fast filter scanning and toggling.
3. Lightweight personal state (preferred maps and custom tags) with clear feedback when persistence fails.
